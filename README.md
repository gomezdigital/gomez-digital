✏️ CUSTOMIZING THE WEBSITE

1. Change the business name

Open:

index.html

Search for:

GOMEZ DIGITAL

Replace it with the client's business name where appropriate.

Example:

GOMEZ DIGITAL

becomes:

FRESH CUTS BW

---

📱 2. Change the WhatsApp number

Open:

script.js

Find:

const phoneNumber = "267XXXXXXXX";

Replace it with the client's WhatsApp number.

IMPORTANT:

Do not use:

- + 
- spaces
- brackets
- dashes

Example:

const phoneNumber = "26771234567";

The number must include the country code.

Botswana country code:

267

---

🔗 3. Change WhatsApp buttons

Open:

index.html

Search for:

https://wa.me/267XXXXXXXX

Replace:

267XXXXXXXX

with the correct WhatsApp number.

Example:

https://wa.me/26771234567

📧 4. Change the email address

index.html

🎨 8. Change the main colour

Open:

style.css

The main accent colour is:

#a8ff35

Search for:

#a8ff35

---

🖼️ 9. Change images

When images are added to the website, replace the image URLs or file names with the client's images.

Use high-quality images that are optimized for websites.

Recommended image formats:

WebP
JPG
PNG

WebP is generally preferred for good quality with smaller file sizes.

---

⭐ 10. Testimonials

The testimonials currently included in the template are DEMO testimonials.

Do NOT present demo testimonials as real customer reviews.

After receiving genuine customer feedback, replace the demo text with verified testimonials.

📱 11. Test the mobile version

Before delivering a website to a client, test:

- Navigation menu
- Buttons
- WhatsApp links
- Contact form
- Pricing cards
- Text readability
- Images
- Scrolling
- Footer
- Different screen sizes

Always test the website on an actual phone if possible.

---

🌐 12. Publish with GitHub Pages

1. Open the GitHub repository.
2. Open Settings.
3. Select Pages.
4. Under Build and deployment, choose:

Deploy from a branch

5. Select:

main

6. Select:

/ (root)

7. Save.

GitHub will build and publish the website.

---

🌐 13. Updating a published website

When you change the website:

1. Open the required file.
2. Edit the content.
3. Commit the changes.
4. Wait for GitHub Pages to redeploy.
5. Refresh the live website.

Your changes should then appear on the live website.
