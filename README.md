# Gomez Digital WebsiteA premium, mobile-first static website built with HTML, CSS and vanilla JavaScript.## Files- `index.html` — website structure and content- `style.css` — responsive design, layout and animations- `script.js` — mobile navigation, WhatsApp links, form handling and scroll reveals- `README.md` — customization and deployment instructions## Before publishingOpen `script.js` and change:```jsconst WHATSAPP_NUMBER = "267XXXXXXXX";```Replace it with the real WhatsApp number in international format, without `+`, spaces or brackets.Example:```jsconst WHATSAPP_NUMBER = "26771234567";```Also replace the placeholder email in `index.html`:```texthello@gomezdigital.example```Replace demo testimonials with real, verified testimonials once you have clients.## Customize a client site1. Change the business name and text in `index.html`.2. Change services and prices.3. Replace contact details.4. Replace testimonials with real feedback.5. Update colors in `style.css` if needed.6. Add client images if desired.7. Test the site on a phone.8. Deploy using GitHub Pages or Netlify.## Free deployment — GitHub Pages1. Create a public GitHub repository.2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.3. Open repository **Settings → Pages**.4. Under Build and deployment, select **Deploy from a branch**.5. Select the `main` branch and `/ (root)`.6. Save and wait for deployment.7. Open the published Pages URL.## Client ownershipFor client work, agree in writing who owns the domain, hosting account and website files. Keep your master template separate from each client's customized project.## ImportantThe listed prices are sample starting prices for the demo and are not a legal quote. Adjust them to your actual Gomez Digital pricing and project scope.
